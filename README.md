# 创新药跨境申报资料

本项目服务于创新药跨法域申报资料。试验数据、翻译文件、法规版本和审评问询共同组成不可篡改的提交包。系统支持清晰的领域对象、事件记录和责任追溯，运行入口提供稳定的健康检查，便于本地联调和运维巡检。

运行 `python3 service.py --check` 可检查基础配置；执行 `python3 service.py --port 8000` 后访问 `/health` 可以确认服务身份。

## 测试

```bash
npm test                      # 契约测试(3) + 领域测试(27)
python3 -m unittest test_domain
```

## 领域模型（domain/）

所有状态变更先落同一条**哈希链事件日志**（`events.py`）：每条事件含前序哈希，
`verify()` 从头重算，任何删除、重排、篡改都会被识破。领域代码经 `clock.py`
取时间，支持按任意时点重放。

| 模块 | 职责 |
| --- | --- |
| `hashing.py` | 全系统唯一的 SHA-256 与确定性 JSON 入口 |
| `artifacts.py` | 内容寻址附件库：按字节哈希存储；同名替换生成新版本，旧版可逐字节取回；重试/幂等键不重复落历史 |
| `study.py` | 药品→试验→受试者分组→分析结果→统计表附件的显式引用，登记即校验，禁止悬空引用 |
| `snapshots.py` | 冻结证据快照：确定性清单 + 清单哈希；冻结后不可改，更新证据只能重冻新快照 |
| `requirements.py` | 各法域要求按 `[effective_from, effective_until)` 时间版本保存，按提交时点取生效版；时限随版本调整 |
| `submissions.py` | 从同一冻结快照生成各法域/语言提交包；译文记录源文件哈希；签章在逐级批准前完成；发送/撤回/重提均追加事件 |
| `inquiries.py` | 审评问询与回复；回复只接受当场通过清单哈希与字节哈希双重校验的冻结快照证据 |
| `workflow.py` | 待办事项：负责人变更只迁移未完成项；时限调整保留轨迹；均产生通知 |
| `notifications.py` | 负责人变更、时限调整的通知记录 |
| `audit.py` | 不信任当前状态，重放事件链精确还原某次递交：逐文件哈希、法规版本、签章状态与凭证、逐级批准人、撤回信息 |
| `app.py` | 装配门面，`verify_integrity()` 做全链巡检 |

### 关键不变量

- **已递交资料不失原貌**：提交包只持有 `snapshot_id + manifest_sha256` 与具体
  版本附件引用；共享盘同名文件更新只产生新版本，旧哈希永不失效。
- **同一份冻结证据，多语言递交**：翻译稿是独立内容寻址附件并回指原件哈希，
  原始分析结果字节永不进包、永不改动。
- **法域差异可回放**：人群、统计表种类、语言、签章要求按时点选版本；建包后
  若法规换版，旧包不能带旧版本直接发送。
- **回复可验证**：问询回复引用的每个哈希都必须属于已验证快照，"最新版"游离
  文件无法进入回复。
- **责任迁移留痕**：负责人变更迁移未完成事项并通知新旧双方；时限调整逐次记录。
- **审计精确**：`audit_submission(package_id)` 返回当天发送的确切文件哈希、
  法规版本、签章（签署人/凭证/签章页哈希）与逐级批准人；`submissions_sent_on(day)`
  按发送日检索。
- **历史不被打断**：上传重试（同内容/幂等键返回原版本）、撤回后重提（新修订版
  带 `revision_of`，旧包保留 `WITHDRAWN`）、同名替换（新版本）都只追加事件。
