# 创新药跨境申报资料

本项目服务于创新药跨法域申报资料。试验数据、翻译文件、法规版本和审评问询共同组成不可篡改的提交包。 系统应支持清晰的领域对象、事件记录和责任追溯，运行入口提供稳定的健康检查，便于本地联调和运维巡检。

运行 `python3 service.py --check` 可检查基础配置；执行 `python3 service.py --port 8000` 后访问 `/health` 可以确认服务身份。

## 领域能力

`regulatory/` 提供跨境申报的领域核心：

- 药品、试验、受试者分组、分析结果与附件建立明确引用；附件按内容哈希寻址，上传重试幂等，同名替换只追加版本，历史不打断。
- 证据快照冻结引用与整体摘要，共享盘文件更新后已冻结证据不失原貌，且可随时重新校验。
- 每个法域的要求（试验人群、统计表、翻译签章、补充问询）按生效时间保存多个版本，并携带截止日期与答复时限。
- 同一份冻结证据可生成不同法域、不同语言的提交包，翻译件单独登记哈希与签章，不改动原始结果；提交包需逐级批准后方可递交。
- 审评问询的答复只能引用可验证的快照；负责人变更或时限调整会迁移未完成事项并留下通知记录。
- 每次递交生成不可变的递交记录，撤回后重提不覆盖历史；审计某次递交可精确还原当天发送的文件哈希、法规版本、签章状态与逐级批准人。

运行 `python3 -m unittest service_contract test_domain` 或 `npm test` 执行全部测试。
